# Telco-Churn-Optimization

Structure initiale du projet de prédiction du churn et d’optimisation des campagnes de rétention.

Les modules, configurations, scripts, tests et fichiers d’infrastructure sont des squelettes à compléter. Les fichiers CSV sont des emplacements réservés : aucune donnée métier n’est fournie. Le fichier poetry.lock est un emplacement réservé, à générer avec Poetry après définition des dépendances.
